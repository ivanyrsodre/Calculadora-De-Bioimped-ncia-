# Calculadora-De-Bioimped-ncia-
Calculadora web de composição corporal em Python, Flask e SQLite. Estima densidade e percentual de gordura pelos protocolos Navy e Jackson–Pollock de 3 e 7 dobras; registra perfis e histórico, gera gráficos e relatórios, exporta CSV e oferece temas claro/noturno, uso simples e somente unidades métricas.
